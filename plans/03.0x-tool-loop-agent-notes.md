# 新练习:ToolLoopAgent(放在 MCP 课程之前)

## 概述
AI SDK v6 引入了 ToolLoopAgent。选项与 `streamText` 等类似。

## system → instructions

ToolLoopAgent 使用 `instructions` 而不是 `system`(与 OpenAI 的命名对齐)。

`streamText`/`generateText` 仍然使用 `system`。只有 ToolLoopAgent 使用 `instructions`。

### 多态的 instructions

之前:仅支持字符串
现在:字符串或部件(parts)数组

部件数组允许为缓存设置不同的提供商选项:

```ts
const agent = new ToolLoopAgent({
  model: "anthropic/claude-sonnet-4.5",
  instructions: [
    { text: 'You are an expert software engineer.', providerOptions: { /* 缓存选项 */ } },
    { text: 'Additional context here.', providerOptions: { /* 不同的缓存 */ } },
  ],
});
```

## 第 1 部分:基础 ToolLoopAgent

```ts
import { ToolLoopAgent } from 'ai';

const agent = new ToolLoopAgent({
  model: "anthropic/claude-sonnet-4.5",
  instructions: 'You are an expert software engineer.',
});
```

## 第 2 部分:使用 createAgentUIStreamResponse 的 API/客户端设置

```ts
// 在你的 API 路由中(例如 app/api/chat/route.ts)
import { createAgentUIStreamResponse } from 'ai';

export async function POST(request: Request) {
  const { messages } = await request.json();

  return createAgentUIStreamResponse({
    agent: myAgent,
    messages,
  });
}
```

将 UIMessage 传递给智能体。

## 第 3 部分:推断智能体类型(智能体即接口)

```ts
import { ToolLoopAgent, InferAgentUIMessage } from 'ai';

const myAgent = new ToolLoopAgent({
  // ... 配置
});

// 为 UI 组件或持久化推断 UIMessage 类型
export type MyAgentUIMessage = InferAgentUIMessage<typeof myAgent>;
```

在需要推断工具结构的 api/客户端设置中使用。
